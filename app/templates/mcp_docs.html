Tích Hợp Vào ChatGPT (Custom GPT Actions)

ChatGPT kết nối với OlokaTTS thông qua giao thức tiêu chuẩn OpenAPI Actions. Sau khi kết nối, bạn chỉ cần chat với GPT là bot có thể tự sinh giọng nói ngay trong cửa sổ chat!

1

Tạo GPT & Mở Cấu Hình

Vào Explore GPTs > Create a GPT, chuyển sang tab Cấu hình (Configure).

2

Cuộn Xuống "Hành Động"

Lăn chuột xuống dưới cùng của cột bên trái (dưới mục Tính năng), bấm nút Tạo hành động mới (Create new action).

3

Nhập URL OpenAPI Hoặc Dán Schema

Bấm nút Nhập từ URL rồi dán link OpenAPI, hoặc dán đoạn mã Schema có sẵn bên dưới.

Hướng Dẫn (Instructions) Điền Cho GPT: 
Bạn là trợ lý lồng tiếng và đọc văn bản tiếng Việt chuyên nghiệp OlokaTTS.
Khi người dùng yêu cầu đọc văn bản hoặc chuyển đổi thành giọng nói:
1. Tự động chọn một giọng đọc phù hợp (hoặc hỏi người dùng):
   - 'Hải Đăng' (Nam miền Nam, tự nhiên, hiện đại - Mặc định)
   - 'Mai Anh' (Nữ miền Bắc, giọng đọc phát thanh viên tin tức)
   - 'Anh Khôi' (Nam miền Bắc, truyền cảm, trầm ấm kể chuyện)
   - 'Quang Sơn' (Nam miền Trung, chân thực, sâu lắng)
   - 'Trúc Ly' (Nữ miền Bắc, trong trẻo, thu hút)
2. Bạn có thể tự nhiên thêm các thẻ cảm xúc như [cười], [thở dài], [thì thầm], [0.5s] vào câu đọc để âm thanh giàu sắc thái biểu cảm.
3. Gọi hành động (action) `generateSpeech` với văn bản và giọng đọc đã chọn.

OpenAI SDK Drop-in & REST API

OlokaTTS hỗ trợ trực tiếp endpoint POST /v1/audio/speech chuẩn của OpenAI. Bạn có thể thay đổi base_url trong thư viện OpenAI chính thức mà không cần sửa code ứng dụng!

Code Mẫu Python (Sử Dụng openai SDK): 
from openai import OpenAI

# Khởi tạo client trỏ về OlokaTTS Gateway
client = OpenAI(
    base_url="{{ gateway_url }}/v1",
    api_key="not-needed"  # Hoặc API Key của bạn nếu đã kích hoạt
)

# Gọi hàm tạo giọng nói tiếng Việt 48kHz
response = client.audio.speech.create(
    model="olokatts-v3-turbo",
    voice="Hải Đăng",  # Hải Đăng, Mai Anh, Anh Khôi, Quang Sơn, Trúc Ly...
    input="Xin chào quý vị! [cười] Đây là giọng đọc trí tuệ nhân tạo OlokaTTS 48kHz.",
    speed=1.0
)

# Lưu trực tiếp ra file âm thanh WAV
response.stream_to_file("vietnamese_output.wav")
print("Đã tạo file vietnamese_output.wav thành công!")
Lệnh cURL Thử Nhanh: 
curl -X POST "{{ gateway_url }}/v1/audio/speech" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "olokatts-v3-turbo",
    "voice": "Mai Anh",
    "input": "Hôm nay thời tiết Hà Nội trời nắng ráo [0.5s], nhiệt độ dao động từ 24 đến 28 độ C.",
    "speed": 1.0
  }' \
  --output "thoi_tiet.wav"

Chi Tiết MCP Tools & Thẻ Cảm Xúc (Emotion Tags)

Các công cụ và thẻ điều khiển giọng đọc mà các AI Agent có thể sử dụng khi tương tác với OlokaTTS.

Tên Hàm (MCP Tool) Tham Số Chính Mô Tả & Kết Quả
generate_speech prompt, voice, speed, output_path Tạo file âm thanh 48kHz WAV, tải về máy cục bộ, hỗ trợ biểu cảm.
list_voices region, gender, editors_pick_only Tra cứu danh sách 25 giọng đọc theo vùng miền (Bắc/Trung/Nam) và giới tính.
get_system_status không Kiểm tra trạng thái GPU Worker Kaggle Dual Tesla T4 và hàng đợi.
estimate_speech_duration text, speed Ước tính số từ, số ký tự và thời lượng phát thanh dự kiến.
